# Security Policy

## Supported versions

frostmarks is pre-release: it has no tagged release yet. Only the `main` branch
gets fixes until the first tag.

After the first tag, the latest `v0` tag and `main` get fixes. A security fix
lands on `main` first, and a later tag carries it.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:
https://github.com/frostyard/frostmarks/security

Open the Security tab and click **Report a vulnerability**.

Do not open a public issue with the details of a vulnerability. Do not post
credentials in an issue, a pull request or a discussion.

## What to include

- The affected commit or version.
- The impact: what an attacker can do.
- The steps to reproduce it.
